About Nova

Purposeful design, useful experiences.

Nova is a sample web application created as a Web Technology project. It demonstrates structured navigation, reusable styling, responsive layout techniques, and separation of HTML, CSS, and JavaScript.

Our goal for this demo is to keep the interface simple, accessible, and easy to explore. Each page has a consistent header, navigation, and footer.

“Make the useful clear, and the clear beautiful.”

— Nova design principle

Make the website work on different screen sizes.
